# Site Factory: интерфейс настольного приложения

Актуальная спецификация от 4 ноября 2026, составлена по прямым указаниям пользователя.
Ранее упомянутый файл отсутствует в доступном проекте; этот документ не является его восстановленной копией.

- Отдельное настольное приложение на компьютере каждого пользователя. Общие данные и генерация — через фоновую службу на Windows или Linux. Сайт-панель не размещается. На странице входа можно импортировать файл подключения к API по IPv4; домен не требуется.
- Основная библиотека компонентов — shadcn/ui (Radix, Tailwind); дополнительные эффекты не обязательны.
- Уточнение пользователя 4 ноября: мягкая тёмная нейтральная палитра по примеру ElevenLabs вместо строгого чёрно-белого контраста. Графитовый фон, слегка отличающиеся поверхности, спокойные серые границы, тёплый светлый основной текст и читаемый вторичный. Приглушённые серые оттенки теперь разрешены и нужны.
- Выразительная типографика, крупные заголовки, чёткая сетка, контрастная чёрная боковая панель. Без фотографий и генерации изображений.
- Рабочая навигация: Сайты, Задания, Серверы, Библиотека, Настройки. В «Серверах» подключение по SSH и прогресс автоматической подготовки пустого Linux VPS.
- Убрать выбор локального/общего режима, Устройство, Расход ресурсов и выбор ролей из нового пользовательского пути.
- Настройка модели: только API-ключ DeepSeek. Endpoint и модель фиксируются сервером.
- Создание: домен, описание темы, оформление, независимый выбор референса из библиотеки через модальное окно с карточками предпросмотра. «Упоминаемая ссылка» обязательна (URL и необязательное пояснение).
- Регистрация и вход — логин и пароль, без email. Регистрация по одноразовому ключу на 20 минут: сначала проверка ключа, затем форма логина и пароля; у всех активных пользователей полные права. Сохранение доступа в выбранный файл на клиенте.
- Видимые состояния загрузки, ошибок и пустого списка; управление с клавиатуры; подписи полей; адаптация к узким экранам.
- Сохранять генерацию, версии, пакетный импорт и библиотеку. Вкладка «Черновик» и редактирование сайтов удалены по указанию пользователя; файлы доступны только для чтения и скачивания. Старый desktop-клиент сохраняется для совместимости, новый серверный путь не использует его исполнителя.
- Публикация на Linux VPS подключена отдельным заданием: показывать реальные этапы и ошибки; статус готовности только после DNS и HTTPS-проверки. Обновление и откат сохраняют IPv4, замена адреса — отдельное действие.

- При остановке генерации показывать причину, конкретный следующий шаг и код задания. Кнопка продолжения доступна только при поддерживаемом восстановлении с контрольной точки.

- Обновление: кнопка создания запускает серверную генерацию и автоматическую публикацию. IPv4 резервируется при создании. По просьбе пользователя обязательные проверки оформления и цикл исправлений отключены; остаются технические ограничения файлов и проверки DNS/HTTPS публикации.

- Пачка: кнопка «Начать конвейер» после успешного запуска открывает «Сайты», отфильтрованные по пачке. Статусы показываются через общий StatusBadge на базе shadcn Badge, со значком и читаемой подписью.

- Для незапущенной пачки доступна кнопка «Удалить пачку». Удаление проверяет версию и состояние на сервере; существующие сайты не удаляются.

- Обновление интерфейса: отдельный раздел «Библиотека» скрыт; референсы остаются в создании. Пояснение ссылки скрыто, импорт CSV/XLSX — отдельная кнопка в заголовке пачки. Режимы заданий объединены ButtonGroup. Убраны служебные подписи в навигации и слоган внизу страниц; бейджи используют спокойные смысловые цвета.

- Уточнение: домен в таблице открывает внешний браузер; шестерёнка открывает настройки. В таблице нет описания темы и служебных подписей хранения; адрес показан только как IPv4. Исходники — скачиваемые карточки в три колонки. В публикации доступен импорт полной новой версии из ZIP с последующей публикацией и откатом. В очереди свойства открываются в общей форме создания в режиме просмотра; сохранённые пачки расположены над формой.
